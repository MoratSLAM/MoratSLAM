# ratslam

This project aims to develop a scientific paper on the application of OpenRatSLAM2, a modern implementation of the RatSLAM algorithm, in an autonomous mobile robot. The study explores the use of neuroscience-inspired cognitive mapping for visual navigation and continuous localization in real-world environments.

The esp32 MAC address is needed to pair the PS4 controller. You can get it using the example code from the PS4Controller library.

Heverton's ESP32S - ESP32_Motors MAC: 4c:11:ae:73:d0:0a

The controller stores the MAC that it is paired, so you need to upload it to the controller. Use the [SixaxisPairTool](https://sixaxispairtool.en.lo4d.com/download) to do it
